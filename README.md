# Project: Rock-Paper-Scissors

This is my first JavaScript project!

The game runs entirely in the console:

- To start the game, just click on one button!
- There are 5 rounds in one game.
- You play against the computer, which makes random choices.
- When the game is over, clicking on one button refresh the page to play again.
- The initial score is 0 for both the user and the computer.

## How a Round Works

- The computer randomly picks Rock, Paper or Scissors.
- The player chooses between Rock, Paper and Scissors.
- The rules are: Rock beats Scissors, Paper beats Rock, and Scissors beat Paper.
- If the user and the computer pick the same choice, the result is a tie (nobody gets a point).
- After every round, the score is shown in the console.

The winner of the game is announced after 5 rounds. The player with the most points wins.
