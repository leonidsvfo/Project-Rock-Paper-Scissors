# Project-Rock-Paper-Scissors

This is my first JavaScript project!

The game works entirely in the console:
- To start the game you should write in the console: console.log(playGame());
- There are 5 rounds in one game;
- You are playing againts the random computer choices;
- When the game is over you should restar the page to play again;
- The intial score is 0 for the user and the computer.

How a Round works
- The console pick a random decision between Rock, Paper and scissors;
- The player should choice between Rock, Paper and Scissors;
- The rules are: Rock beats scissors, paper beats rock, scissors beat paper;
- if the user and the computer pick the same choice the output is parity (nobody gets a point);
- after every round you can see the score in the console.

The winner of the game is shown after 5 rounds. The player with most points wins.
